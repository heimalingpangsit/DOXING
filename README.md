## 📥 Instalasi (Satu File + Database)

### Metode  Instalasi 
```bash
buka link di paling bawah "Source kode" lalu simpan di direktori yang kamu bisa akses ( jangan sdcard)
lalu masuk ke terminal kamu lalu lakukan $ cd /sdcard/download/
lalu lakukan unzip di package tersebut dengan cara unzip doxing.zip
lalu jalankan python zet3.py



# $ cd /sdcard/download
# $ unzip doxing.zip
# $ python zet3.py
# selamat anda telah menjadi kang doxing
```
## 🚀 Cara Pakai & Menjalankan script 
```bash
python3 zet3.py
```
## Pilih database:
```bash
1. Dukcapil   → Data Kependudukan
2. BPJS       → Data BPJS Kesehatan
3. NIK Indo   → Data KTP
4. Nomor      → Data Nomor HP
5. NPWP       → Data Pajak
```
